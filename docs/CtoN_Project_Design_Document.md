# CtoN 项目设计文档

版本：1.0\
项目名称：CtoN（Chongqing to Nanjing）\
项目类型：气象数据驱动的高铁旅行可视化系统\
开发语言：Python\
数据库：SQLite

------------------------------------------------------------------------

# 1. 项目背景

CtoN 的灵感来源于一次真实的高铁旅行体验。

项目开发者是一名应用气象学本科学生，长期往返于重庆与南京之间。在接近九小时的高铁旅途中，可以明显观察到沿线地区天气、地形、气候环境以及空气质量的变化。

传统天气应用主要提供单个城市的天气查询，而 CtoN
希望通过一条高铁线路，将多个城市连接起来，展示一次完整的气象空间变化过程。

项目定位：

> 一个展示重庆到南京高铁沿线城市天气变化、气象环境特征以及城市文化气象体验的可视化系统。

------------------------------------------------------------------------

# 2. 项目目标

## 2.1 核心目标

实现一个可以通过浏览器访问的网站：

-   展示重庆到南京高铁路线
-   显示沿线主要城市天气
-   展示气象要素变化
-   分析大气稳定度
-   展示空气质量变化
-   根据天气图片显示城市预设诗句，并生成全线路旅途建议

------------------------------------------------------------------------

# 3. 产品定位

CtoN 不是简单的天气查询网站，而是：

> 气象数据驱动的高铁旅行可视化探索平台。

核心体验：

用户打开网站：

1.  看到重庆到南京高铁路线地图
2.  高铁沿线路径展示
3.  点击城市查看当地气象信息
4.  查看温度、天气、污染、大气状态
5.  查看沿线气象变化趋势
6.  阅读城市诗句和 AI 生成的全线路旅途建议

------------------------------------------------------------------------

# 4. 功能设计

## 4.1 首页地图系统

首页以重庆到南京高铁路线地图作为主要视觉区域。

功能：

-   展示路线
-   展示城市节点
-   点击城市进入详情页面
-   随机探索城市
-   高铁移动动画

推荐效果：

高铁图标沿路线移动，经过城市时展示当前天气状态。

------------------------------------------------------------------------

# 4.2 城市天气详情

每个城市展示：

## 基础天气

-   当前温度
-   天气状况
-   体感温度
-   湿度
-   风速
-   风向
-   降水概率
-   能见度

## 空气质量

-   AQI
-   PM2.5
-   PM10
-   主要污染物

## 气象分析

展示：

-   大气稳定度
-   温度直减率
-   环境解释

例如：

弱不稳定：

午后地面加热增强，垂直混合作用增强，有利于污染扩散。

------------------------------------------------------------------------

# 4.3 气象剖面

为了体现应用气象专业特色，系统提供沿线气象变化图。

包括：

-   温度剖面
-   湿度变化
-   AQI变化
-   风速变化

横轴：

高铁距离

纵轴：

气象变量

体现：

一次旅行过程中气象环境的空间变化。

------------------------------------------------------------------------

# 4.4 天气诗句展示

根据：

-   城市
-   天气
-   温度
-   季节
-   城市文化

从与城市天气图片绑定的静态注册表中选择两句诗。

示例：

重庆：

巴山雾起江风晚， 一城灯火入云间。

选择逻辑：天气数据 → 季节和天气类型 → 城市图片 → 对应预设诗句。每张图片固定一首五言或七言两句诗，不调用外部模型。

------------------------------------------------------------------------

# 4.5 气象旅行模式

页面默认从重庆北站开始自动巡游。每个城市的展示周期为 10 秒，高铁图标在周期结束前移动到下一站，抵达时切换当前城市。到达南京南站后，图标淡出并在重庆北站重新出现，然后继续循环。

用户可以暂停或继续自动巡游，也可以直接点击沿线站点切换城市。手动选择后，自动巡游从新站重新计时。

用户也可点击：

"随机旅行"

随机进入一个其他城市，并从该站重新开始自动巡游计时。

展示：

-   当前所在城市
-   高铁路线位置
-   天气
-   气象特点
-   与城市图片对应的预设诗句

增加探索体验。

------------------------------------------------------------------------

# 4.6 旅行建议模式

用户点击“更新观测”后，根据当天沿线数据生成 50–100 个汉字的旅途建议。

内容：

-   沿线温差和天气变化
-   穿衣建议
-   雨具建议
-   防暑建议
